# Task: Build Product Hunt collector (highest value data source)

## Description
Implement a comprehensive Product Hunt data collector to gather daily launches, product details, maker information, and engagement metrics. Product Hunt is the primary source for new app discoveries with rich metadata.

## Project Structure Guidelines
- Create project in subfolder `app-radar/`
- All project files go in the subfolder
- Root directory stays clean

## Implementation Steps
1. Study Product Hunt's structure and data patterns
2. Implement Product Hunt collector class extending base collector
3. Build product discovery logic (daily launches, trending products)
4. Extract comprehensive product data (name, description, maker, website, metrics)
5. Handle Product Hunt's dynamic loading and pagination
6. Implement maker profile data collection
7. Add category and tag extraction
8. Create data enrichment pipeline (screenshots, additional metadata)
9. Implement incremental updates and deduplication

## Acceptance Criteria
- [ ] Can collect daily Product Hunt launches automatically
- [ ] Extracts complete product metadata (name, description, URL, metrics)
- [ ] Collects maker information and profiles
- [ ] Handles pagination and dynamic content loading
- [ ] Implements proper rate limiting and error handling
- [ ] Stores data in structured format
- [ ] Supports incremental updates
- [ ] Includes data validation and quality checks

## Technical Details
- Use Playwright to handle dynamic JavaScript content
- Implement smart waiting strategies for dynamic loading
- Add screenshot capture for visual product records
- Use CSS selectors and XPath for reliable data extraction
- Implement data normalization and cleaning
- Add retry logic for failed requests

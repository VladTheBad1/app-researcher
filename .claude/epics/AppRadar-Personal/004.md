# Task: Build Twitter/X collector (real-time launches)

## Description
Implement a Twitter/X data collector to capture real-time app launches, founder announcements, and community discussions. Twitter provides immediate notifications of new products and real-time sentiment.

## Project Structure Guidelines
- Create project in subfolder `app-radar/`
- All project files go in the subfolder
- Root directory stays clean

## Implementation Steps
1. Research Twitter/X data collection strategies and limitations
2. Implement Twitter collector class extending base collector
3. Set up hashtag and keyword monitoring (#buildinpublic, #indiehackers, #launch)
4. Build profile monitoring for known founders and companies
5. Implement tweet content analysis and link extraction
6. Add engagement metrics collection (likes, retweets, replies)
7. Create thread reconstruction for multi-tweet announcements
8. Implement real-time monitoring capabilities
9. Add sentiment analysis and trend detection

## Acceptance Criteria
- [ ] Can monitor relevant hashtags and keywords
- [ ] Tracks founder profiles and company accounts
- [ ] Extracts launch announcements and product links
- [ ] Collects engagement metrics and social proof
- [ ] Reconstructs tweet threads for complete context
- [ ] Implements real-time or near-real-time collection
- [ ] Filters noise and identifies genuine product launches
- [ ] Handles Twitter's rate limiting and access restrictions

## Technical Details
- Navigate Twitter/X's dynamic interface and infinite scroll
- Implement intelligent content filtering and classification
- Handle various tweet formats (text, images, links, threads)
- Add duplicate detection across tweet variations
- Implement smart rate limiting to avoid blocks
- Use CSS selectors resilient to interface changes

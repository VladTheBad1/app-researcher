# Task: Setup Playwright MCP and browser automation foundation

## Description
Establish the core browser automation infrastructure using Playwright MCP for collecting app data from various sources. This foundation will enable automated data collection from Product Hunt, IndieHackers, Twitter/X, and Exploding Topics.

## Project Structure Guidelines
- Create project in subfolder `app-radar/`
- All project files go in the subfolder
- Root directory stays clean

## Implementation Steps
1. Create `app-radar/` project directory structure
2. Install and configure Playwright MCP integration
3. Set up browser automation utilities (headless Chrome setup, user agent rotation, rate limiting)
4. Create base collector class with common functionality (error handling, retry logic, data validation)
5. Implement data storage layer (JSON files, database schema)
6. Add logging and monitoring infrastructure
7. Create configuration management system for API keys and settings

## Acceptance Criteria
